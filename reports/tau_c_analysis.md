## 3. τ_c 确定过程

两种口径：**Δ_t 比值**（系数法）和 **正确率地板线**（业务指标法）。
综合 τ_c 取两者较小值（保守估计）。

- 退化判定 1（Δ_t 比值）：后 1/2 Δ_t > 上一档 × 1.5
- 退化判定 2（正确率地板）：correct_rate < 0.8
- 条件 B 退化点（Δ_t 比值）：  - τ 0.55 → 0.60 (×3.00)
  - τ 0.60 → 0.65 (×2.00)
  - τ 0.80 → 0.90 (×2.00)
- 条件 D 退化点（Δ_t 比值）：  - (无)

- **τ_c_B (Δ_t 口径)** = `0.55`
- **τ_c_B (正确率口径)** = `0.9`
- **τ_c_B (综合)** = `0.55`
- **τ_c_D (Δ_t 口径)** = `1.0`
- **τ_c_D (正确率口径)** = `0.9`
- **τ_c_D (综合)** = `0.9`
- **τ_c (ARGUS 经验值)** = `min(τ_c_B, τ_c_D)` = `0.55`

| τ | 理论下界 (1-τ)/2 | 实测退化点 |
|---|----------------|------------|
| 0.55 | 0.225 | - |

| 1.00 | 0.000 | - |

> 注：理论下界是"任意时刻一个裁判的翻转概率"，
> 实测退化点是"系统经过若干轮后 Δ_t 显著上升"的临界 τ 值。
> 两者口径不同：理论下界等价于我们的 1/(1+2N)（多轮平均）；
> 但 Ratchet 未考虑 LLM 累积误差与 L2+ 难度无效任务。

## 5. 结论

- ARGUS 在条件 B 下，τ ≤ 0.55 才不显著退化（Δ_t 稳态不飙升）；
  τ ≥ 0.9500000000000001 时正确率仍 ≥ 80%
- ARGUS 在条件 D 下，τ ≤ 1.0 才不显著退化；
  τ ≥ 0.9500000000000001 时正确率仍 ≥ 80%
- 经验值与理论下界 `1/(1+2N) / 2` 的对比说明：
  - 真实系统中"微小翻转"会被 Z3 锚定 + 蒸馏反馈吸收，
  - 但持续大量翻转会让学生/蒸馏学到错误的"成功经验"，
    从而在后期 Δ_t 才显示出累积效应。
