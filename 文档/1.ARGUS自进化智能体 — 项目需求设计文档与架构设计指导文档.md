# ARGUS自进化Agent架构 — 工程开发文档

**版本**: v1.0 | **目标读者**: DeepSeek Harness (dsh) 开发Agent | **部署环境**: AutoDL RTX 4090 + DeepSeek V4 Flash API


## 第一部分：dsh能力边界与规避策略

### 1.1 dsh的已知不足与规避设计

在开发之前，先明确dsh在Agent开发场景下的已知限制，并在需求设计中系统性规避：

**已知问题一：子Agent写入受阻。** 在dsh v0.1.1-rc.2中，通过内置spawn/fork创建的进程内子Agent，虽然继承了父会话的workspace-write沙箱权限，但由于模型面向工具表面仍暴露了registry-global的escalation参数（sandbox_permissions和justification），普通写入调用会被审批校验拒绝，导致子Agent实际上变成只读。**规避策略**：ARGUS架构中所有Agent的文件写入操作不通过dsh的subagent工具，而是通过统一的`FileStore`插件（见第2.2节）在父会话中集中管理。

**已知问题二：叙述但不调用的输出循环。** Agent在多轮长会话中容易陷入“输出叙述文本但不实际调用工具”的循环，需要用户手动打断。**规避策略**：ARGUS的每个Agent角色必须使用明确的工具调用schema，系统提示词中禁止任何叙述性输出，所有输出必须是结构化的JSON。

**已知问题三：Code mode下`{{...}}`字面量导致prompt组装失败。** 如果工具描述中包含字面量`{{...}}`，Code mode的prompt组装会失败。**规避策略**：ARGUS的所有工具描述和系统提示词中，禁止使用`{{`和`}}`字符。

**已知问题四：token消耗大、速度慢。** 社区实测显示dsh的token消耗较大，有用户先在Pi Harness做规划再拿到DSH重做，省了约20M token。**规避策略**：ARGUS的API调用使用DeepSeek V4 Flash的缓存命中机制，所有系统提示词放在最前缀以最大化缓存命中率（目标>85%）。

**已知问题五：Developer Preview阶段的不稳定性。** dsh的API可能在版本之间发生不兼容变更，且尚未经过安全审计。**规避策略**：ARGUS的所有dsh插件实现依赖最小化的dsh API面，只使用核心的插件注册、会话管理和工具注册接口。

```python
class LLMClient:
    def __init__(self, api_key: str, base_url: str = "https://api.deepseek.com/v1"):
        self.client = OpenAI(api_key=api_key, base_url=base_url)
        self.cache = SQLiteCache("llm_cache.db")
        self.circuit_breaker = CircuitBreaker(max_failures=5, reset_timeout=30)
    
    def call(self, system: str, user: str, temperature: float = 0.7, 
             max_tokens: int = 4096, task_id: str = None) -> str:
        # 1. 检查本地缓存
        cache_key = hash(system + user)
        if self.cache.has(cache_key):
            return self.cache.get(cache_key)
        
        # 2. 熔断器检查
        if self.circuit_breaker.is_open():
            raise CircuitBreakerOpen("LLM API熔断中，请等待")
        
        # 3. 指数退避重试（最多3次）
        for attempt in range(3):
            try:
                response = self.client.chat.completions.create(
                    model="deepseek-v4-flash",
                    messages=[
                        {"role": "system", "content": system},
                        {"role": "user", "content": user}
                    ],
                    temperature=temperature,
                    max_tokens=max_tokens
                )
                result = response.choices[0].message.content
                self.cache.set(cache_key, result)
                self.circuit_breaker.record_success()
                return result
            except Exception as e:
                self.circuit_breaker.record_failure()
                if attempt < 2:
                    time.sleep(2 ** attempt + random.uniform(0, 1))
                else:
                    raise LLMCallFailed(f"LLM调用失败（已重试3次）: {e}")
```

**验收标准**：
- 缓存命中率 ≥ 80%（通过日志统计）
- 429错误后自动恢复成功率 ≥ 95%
- 熔断器在连续5次失败后30秒内打开，半开状态测试通过率 ≥ 90%

class ExperienceStore:
    def __init__(self, db_path: str = "experiences.db"):
        self.conn = sqlite3.connect(db_path)
        self.conn.execute("PRAGMA journal_mode=WAL")  # 并发读写不阻塞
        self._init_tables()
        self.index = faiss.IndexFlatL2(768)  # 向量索引
    
    def _init_tables(self):
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS principles (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                principle TEXT NOT NULL,
                context_vector BLOB,
                rule_type TEXT CHECK(rule_type IN ('positive', 'negative')),
                confidence REAL DEFAULT 0.5,
                retrieval_count INTEGER DEFAULT 0,
                success_count INTEGER DEFAULT 0,
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
                half_life INTEGER DEFAULT 100,
                generation INTEGER DEFAULT 0,
                is_active INTEGER DEFAULT 1
            )
        """)
        self.conn.execute("""
            CREATE TABLE IF NOT EXISTS task_log (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                task_id TEXT UNIQUE,
                difficulty_level INTEGER,
                constraint_code TEXT,
                agent_output TEXT,
                llm_self_score REAL,
                z3_result TEXT,
                z3_latency_ms REAL,
                token_input INTEGER,
                token_output INTEGER,
                round_number INTEGER,
                condition TEXT,
                keep INTEGER,
                git_commit TEXT,
                created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
            )
        """)
    
    def add_principle(self, principle: str, context_vec: np.ndarray, 
                      rule_type: str) -> int:
        """添加经验原则"""
        cursor = self.conn.execute(
            "INSERT INTO principles (principle, context_vector, rule_type) VALUES (?, ?, ?)",
            (principle, context_vec.tobytes(), rule_type)
        )
        self.conn.commit()
        idx = cursor.lastrowid
        self.index.add(context_vec.reshape(1, -1))
        return idx
    
    def retrieve(self, query_vec: np.ndarray, top_k: int = 5) -> List[dict]:
        """检索最相关的经验原则"""
        distances, indices = self.index.search(query_vec.reshape(1, -1), top_k)
        results = []
        for i, idx in enumerate(indices[0]):
            if idx == -1:
                continue
            row = self.conn.execute(
                "SELECT * FROM principles WHERE id = ? AND is_active = 1", (idx,)
            ).fetchone()
            if row:
                results.append(dict(zip([c[0] for c in self.conn.description], row)))
                # 更新检索计数
                self.conn.execute(
                    "UPDATE principles SET retrieval_count = retrieval_count + 1 WHERE id = ?", (idx,)
                )
        self.conn.commit()
        return results
```

**验收标准**：
- FAISS检索延迟 ≤ 100ms（百万级向量）
- SQLite WAL模式并发读写无阻塞
- 经验原则去重率 ≥ 90%（语义相似度 > 0.95的规则被合并）

class AntibodyStore:
    def __init__(self, db_path: str = "antibodies.db"):
        self.conn = sqlite3.connect(db_path)
        self.conn.execute("""
            CREATE VIRTUAL TABLE IF NOT EXISTS antibodies USING fts5(
                failure_signature,
                repair_strategy,
                success_count,
                last_used
            )
        """)
    
    def record_repair(self, failure_sig: str, repair: str):
        """记录成功修复"""
        self.conn.execute(
            "INSERT INTO antibodies (failure_signature, repair_strategy, success_count, last_used) "
            "VALUES (?, ?, 1, CURRENT_TIMESTAMP)",
            (failure_sig, repair)
        )
        self.conn.commit()
    
    def find_repair(self, failure_sig: str, limit: int = 3) -> List[dict]:
        """检索相似失败模式的修复方案"""
        cursor = self.conn.execute(
            "SELECT repair_strategy, success_count FROM antibodies "
            "WHERE antibodies MATCH ? ORDER BY success_count DESC LIMIT ?",
            (failure_sig, limit)
        )
        return [{"repair": row[0], "success_count": row[1]} for row in cursor.fetchall()]

class MethylationStore:
    def __init__(self, path: str = "methylation.json"):
        self.path = path
        self.markers = self._load()
    
    def write(self, context_hash: str, behavior_rule: str, half_life: int = 100):
        """写入甲基化标记"""
        self.markers[context_hash] = {
            "rule": behavior_rule,
            "half_life": half_life,
            "activation_count": 0,
            "last_activated": time.time(),
            "is_active": True
        }
        self._save()
    
    def activate(self, context_hash: str) -> Optional[str]:
        """激活匹配的标记"""
        if context_hash in self.markers:
            marker = self.markers[context_hash]
            if marker["is_active"]:
                marker["activation_count"] += 1
                marker["last_activated"] = time.time()
                self._save()
                return marker["rule"]
        return None
    
    def decay(self):
        """衰减未被激活的标记"""
        now = time.time()
        for key, marker in self.markers.items():
            elapsed = now - marker["last_activated"]
            if elapsed > marker["half_life"] and marker["activation_count"] == 0:
                marker["is_active"] = False
        self._save()
```

**验收标准**：
- 标记写入/读取延迟 ≤ 10ms
- 衰减机制正确执行（连续未激活的标记在half_life后失活）

                   "Output ONLY the Python code that creates the Z3 solver.",
        "verifier": "You are a verification agent. Given a Z3 constraint set and "

                    "Output JSON: {{\"correct\": true/false, \"reason\": \"...\"}}"

        self.role = role
        self.system_prompt = self.ROLES[role]
        self.llm = llm_client
        self.memory = memory
    
    def execute(self, task_input: str, context: dict = None) -> dict:
        """执行任务，带免疫修复"""
        # 1. 检索相关经验

            np.random.randn(768), top_k=3  # 实际使用task_input的嵌入

            user=user_prompt,

            return False

**模块：`argus-apoptosis`（凋亡机制）**

```python
class ApoptosisManager:
    def __init__(self, entropy_threshold: float = 0.3, 
                 performance_threshold: float = 0.5,
                 window_size: int = 3):
        self.entropy_threshold = entropy_threshold
        self.performance_threshold = performance_threshold
        self.window_size = window_size
        self.history = []
    
    def check(self, agent_id: str, recent_outputs: List[str], 
              recent_success_rate: float) -> bool:
        """检查是否应触发凋亡"""
        # 1. 检查输出熵
        if len(recent_outputs) >= self.window_size:
            entropy = self._compute_entropy(recent_outputs[-self.window_size:])
            if entropy < self.entropy_threshold:
                return True
        
        # 2. 检查性能
        if recent_success_rate < self.performance_threshold:
            return True
        
        return False
    
    def _compute_entropy(self, outputs: List[str]) -> float:
        """计算输出多样性（归一化香农熵）"""
        import math
        from collections import Counter
        # 使用n-gram的多样性作为近似
        all_ngrams = []
        for out in outputs:
            words = out.split()
            all_ngrams.extend([tuple(words[i:i+2]) for i in range(len(words)-1)])
        if not all_ngrams:
            return 0.0
        counter = Counter(all_ngrams)
        total = sum(counter.values())
        probs = [c/total for c in counter.values()]
        entropy = -sum(p * math.log(p) for p in probs if p > 0)
        max_entropy = math.log(len(counter)) if len(counter) > 1 else 1
        return entropy / max_entropy if max_entropy > 0 else 0.0
    
    def extract_seed(self, agent_id: str, memory: ExperienceStore) -> dict:
        """提取种子"""
        top_principles = memory.conn.execute(
            "SELECT principle, rule_type, success_count FROM principles "
            "WHERE is_active = 1 ORDER BY success_count DESC LIMIT 5"
        ).fetchall()
        return {
            "agent_id": agent_id,
            "top_principles": [{"text": p[0], "type": p[1], "success": p[2]} 
                              for p in top_principles],
            "timestamp": time.time()
        }
```

**验收标准**：
- 凋亡触发准确率 ≥ 80%（人工审核确认）
- 种子提取包含Top-5成功规则和Top-3失败教训

### 2.4 L3评测层

**模块：`argus-z3-anchor`（形式锚定验证器）**

这是ARGUS的“防自嗨阀”，所有Z3任务必须通过此模块验证。

```python
class Z3Anchor:
    def __init__(self, timeout_ms: int = 10000):
        self.timeout_ms = timeout_ms
        self.stats = {"total": 0, "sat": 0, "unsat": 0, "timeout": 0, "error": 0}
    
    def verify(self, constraint_code: str) -> dict:
        """验证Z3约束集，返回真值"""
        self.stats["total"] += 1
        start = time.time()
        
        try:
            from z3 import Solver, sat, unsat
            # 沙箱执行
            local_vars = {}
            exec(constraint_code, {"__builtins__": {"__import__": __import__}}, local_vars)
            solver = local_vars.get("solver")
            if not solver:
                self.stats["error"] += 1
                return {"status": "error", "reason": "no_solver", "latency_ms": 0}
            
            result = solver.check()
            latency = (time.time() - start) * 1000
            
            if result == sat:
                self.stats["sat"] += 1
                model = solver.model()
                return {"status": "sat", "model": str(model), "latency_ms": latency}
            elif result == unsat:
                self.stats["unsat"] += 1
                return {"status": "unsat", "latency_ms": latency}
            else:
                self.stats["timeout"] += 1
                return {"status": "unknown", "latency_ms": latency}
        except Exception as e:
            self.stats["error"] += 1
            return {"status": "error", "reason": str(e), "latency_ms": (time.time()-start)*1000}
    
    def get_stats(self) -> dict:
        return {**self.stats, "success_rate": (self.stats["sat"] + self.stats["unsat"]) / max(self.stats["total"], 1)}
```

**验收标准**：
- 验证延迟中位数 ≤ 10ms
- SAT/UNSAT判断准确率 100%（Z3是确定性的）
- 错误率 ≤ 1%（无效代码被正确拒绝）

```python
class RoundTable:
    PERSONAS = [
        ("风险分析师", "你关注约束集的边界情况和潜在矛盾。"),
        ("第一性原理者", "你从最基本的逻辑公理出发分析问题。"),
        ("魔鬼代言人", "你试图找出约束集的漏洞和不可满足性。"),
        ("领域专家", "你基于SMT求解的最佳实践提供判断。")
    ]
    
    def __init__(self, llm_client: LLMClient, max_rounds: int = 2):
        self.llm = llm_client
        self.max_rounds = max_rounds
    
    def consensus(self, question: str, candidates: List[str]) -> dict:
        """执行圆桌共识协议"""
        # 第1轮：盲评
        scores = {}
        for persona_name, persona_prompt in self.PERSONAS:
            response = self.llm.call(
                system=f"你是{persona_name}。{persona_prompt}",
                user=f"问题: {question}\n\n候选答案:\n" + "\n".join(
                    f"{i}. {c}" for i, c in enumerate(candidates)
                ) + "\n\n请为每个候选答案打分(0-100)，输出JSON: {{\"scores\": [...]}}"
            )
            parsed = json.loads(response)
            for i, score in enumerate(parsed["scores"]):
                scores.setdefault(i, []).append({
                    "score": score,
                    "confidence": score,  # 简化：自评置信度=评分
                    "persona": persona_name
                })
        
        # 计算加权得分
        weighted = {}
        for i, entries in scores.items():
            weighted[i] = sum(e["score"] * e["confidence"] for e in entries) / sum(e["confidence"] for e in entries)
        
        # 收敛检测
        best_idx = max(weighted, key=weighted.get)
        best_score = weighted[best_idx]
        total = sum(weighted.values())
        
        return {
            "consensus_answer": candidates[best_idx],
            "consensus_confidence": best_score / total if total > 0 else 0,

            "all_scores": weighted
        }

class JudgeCalibrator:
    def __init__(self):
        self.judge_history = {}  # judge_id -> {task_type -> accuracy}
    
    def update(self, judge_id: str, task_type: str, correct: bool):
        """更新判官准确率"""
        key = (judge_id, task_type)
        if key not in self.judge_history:
            self.judge_history[key] = {"total": 0, "correct": 0}
        self.judge_history[key]["total"] += 1
        if correct:
            self.judge_history[key]["correct"] += 1
    
    def get_weight(self, judge_id: str, task_type: str) -> float:
        """获取判官权重"""
        key = (judge_id, task_type)
        if key not in self.judge_history:
            return 1.0  # 默认权重
        stats = self.judge_history[key]
        if stats["total"] < 5:
            return 1.0
        return stats["correct"] / stats["total"]
```

**验收标准**：
- 低可靠判官（准确率 < 0.5）权重被降至 ≤ 0.3
- 校准后判官一致性（Cohen’s kappa）提升 ≥ 0.1

```python
class PopulationGame:
    def __init__(self, llm_client: LLMClient, z3_anchor: Z3Anchor, 
                 population_size: int = 3):
        self.llm = llm_client
        self.z3 = z3_anchor
        self.population_size = population_size
        self.difficulty_levels = {1: 10, 2: 20, 3: 30}  # 变量数
    
    def run_round(self, round_num: int, current_level: int) -> dict:
        """运行一轮种群博弈"""
        # 教师生成任务
        task = self._teacher_generate(current_level)
        
        # 验证任务有效性
        task_verification = self.z3.verify(task["constraint_code"])
        if task_verification["status"] == "error":
            return {"status": "invalid_task", "reason": task_verification.get("reason")}
        
        # 学生解题
        solutions = []
        for i in range(self.population_size):
            sol = self._solver_attempt(task["constraint_code"])
            solutions.append(sol)
        
        # Z3验证
        results = []
        for sol in solutions:
            if sol["status"] == "error":
                results.append({"correct": False, "reason": "solver_error"})
                continue
            correct = (sol["answer"] == task_verification["status"])
            results.append({"correct": correct, "answer": sol["answer"], 
                          "expected": task_verification["status"]})
        
        # 难度自适应
        success_rate = sum(1 for r in results if r["correct"]) / len(results)
        new_level = current_level
        if success_rate > 0.8 and current_level < 3:
            new_level = current_level + 1
        elif success_rate < 0.3 and current_level > 1:
            new_level = current_level - 1
        
        return {
            "round": round_num,
            "task": task,
            "task_verification": task_verification,
            "solutions": results,
            "success_rate": success_rate,
            "difficulty_level": new_level,
            "level_changed": new_level != current_level
        }
```

**验收标准**：
- 难度从Level 1扩展到Level 3的轮次 ≤ 100
- 伪难题（LLM认为难但Z3可轻松求解）比例在条件D中 < 5%，在条件C中 > 20%
- 种群中最弱成员的最终正确率 ≥ 基线

Current system prompt:

Performance metrics:
- Success rate: {artifact.get('success_rate', 'N/A')}

Generate an improved version of this prompt. The improvement should:

3. Reduce token consumption

Output ONLY the new prompt text, no explanation."""

```python
class CheckpointManager:
    def __init__(self, base_dir: str = "checkpoints"):
        self.base_dir = base_dir
        os.makedirs(base_dir, exist_ok=True)
    
    def create(self, state: dict, tag: str = None) -> str:
        """创建检查点"""
        tag = tag or f"cp_{int(time.time())}_{uuid.uuid4().hex[:8]}"
        path = os.path.join(self.base_dir, tag)
        os.makedirs(path, exist_ok=True)
        
        # 保存所有可编辑工件
        for key, value in state.items():
            filepath = os.path.join(path, f"{key}.json")
            with open(filepath, "w") as f:
                json.dump(value, f, ensure_ascii=False, indent=2)
        
        # 保存git commit hash
        try:
            result = subprocess.run(["git", "rev-parse", "HEAD"], 
                                   capture_output=True, text=True)
            with open(os.path.join(path, "git_commit.txt"), "w") as f:
                f.write(result.stdout.strip())
        except:
            pass
        
        return tag
    
    def rollback(self, tag: str):
        """回滚到指定检查点"""
        path = os.path.join(self.base_dir, tag)
        if not os.path.exists(path):
            raise ValueError(f"Checkpoint {tag} not found")
        
        # 恢复文件
        for filename in os.listdir(path):
            if filename == "git_commit.txt":
                continue
            key = filename.replace(".json", "")
            with open(os.path.join(path, filename)) as f:
                state = json.load(f)
            # 恢复逻辑（由调用方处理）
        
        return state
```

**验收标准**：
- 检查点创建延迟 ≤ 100ms
- 回滚后系统状态与检查点完全一致
