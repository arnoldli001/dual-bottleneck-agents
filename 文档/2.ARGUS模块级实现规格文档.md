## 1.2 函数签名

```python
def verify_z3(code: str, timeout_ms: int = 10000) -> dict:
    """
    安全执行Z3 Python代码，返回验证结果。

    Args:
        code: 完整的Python代码字符串，必须包含 solver = Solver() 和 solver.check()
        timeout_ms: 超时毫秒数，默认10000

    Returns:
        dict: {
            "status": "sat" | "unsat" | "unknown" | "error",
            "model": str | None,        # status=="sat"时返回模型字符串
            "latency_ms": float,        # 执行耗时
            "reason": str | None,       # status=="error"时返回原因
            "error_code": int | None    # 0=无错误, 1=语法错误, 2=缺少solver,
                                        # 3=危险导入, 4=超时, 5=运行时异常
        }
    """
```

## 1.3 输入示例

```python
# 有效SAT代码
code_sat = '''
from z3 import *
x = Int('x')
solver = Solver()
solver.add(x > 5)
solver.add(x < 10)
solver.check()
'''

# 有效UNSAT代码
code_unsat = '''
from z3 import *
x = Int('x')
solver = Solver()
solver.add(x > 5)
solver.add(x < 3)
solver.check()
'''

# 无效代码（语法错误）
code_invalid = 'x = Int(x'
```

## 1.5 处理流程

```
1. 记录开始时间 start = time.time()

2. 语法检查（ast.parse）
   - 失败 → 返回 error_code=1, status="error", reason=str(e)

3. 危险导入检查
   - 检查代码字符串中是否包含以下任一：
     "import os", "import sys", "import subprocess", "import shutil",
     "__import__", "eval(", "exec(", "open(", "file("
   - 如果包含 → 返回 error_code=3, status="error",
     reason="Dangerous import/call detected: {found}"

4. 执行代码（exec，捕获所有异常）
   - 设置全局命名空间：{"__builtins__": {"__import__": __import__}}
   - 执行 exec(code, namespace)
   - 检查 namespace 中是否定义了 "solver" 变量
   - 未定义 → 返回 error_code=2, status="error", reason="solver not defined"
   - 运行时异常 → 返回 error_code=5, status="error", reason=str(e)

5. 调用 solver.check()（带超时）
   - 使用 threading.Timer 设置超时
   - 超时 → 返回 error_code=4, status="unknown", reason="timeout"
   - 返回 sat → 提取 model，status="sat", model=str(solver.model())
   - 返回 unsat → status="unsat", model=None
   - 返回 unknown → error_code=4, status="unknown", reason="solver returned unknown"

6. 计算延迟 latency_ms = (time.time() - start) * 1000

7. 返回结果字典
```

## 1.6 边界条件

| 场景 | 输入 | 预期输出 |
|------|------|----------|
| 空字符串 | `""` | error_code=1, status="error" |
| 只有import | `"from z3 import *"` | error_code=2, status="error" |
| 危险导入 | `"import os\nsolver=Solver()"` | error_code=3, status="error" |
| 无限循环 | `"while True: pass"` | error_code=4, status="unknown" |
| 空Solver | `"solver=Solver()\nsolver.check()"` | status="sat" |
| 复杂约束 | 30变量混合理论 | 正常返回，延迟可能>100ms |
| 重复solver | `"solver=Solver()\nsolver=Solver()"` | 使用最后一个solver |

## 3.3 缓存机制

```python
class SQLiteCache:
    """本地SQLite缓存，减少重复API调用。"""

    def __init__(self, db_path: str = "llm_cache.db"):
        """初始化缓存数据库，创建表结构。"""

    def _hash(self, system: str, user: str) -> str:
        """计算缓存键: SHA256(system + "|||" + user)"""

    def get(self, key: str) -> Optional[str]:
        """获取缓存，未命中返回None。"""

    def set(self, key: str, value: str):
        """写入缓存，包含时间戳。"""

    def clear(self):
        """清空缓存。"""
```

## 3.4 熔断器

```python
class CircuitBreaker:
    """熔断器，防止API连续失败导致雪崩。"""

    def __init__(self, max_failures: int = 5, reset_timeout: int = 30):
        """
        Args:
            max_failures: 连续失败次数阈值
            reset_timeout: 熔断后恢复等待秒数
        """

    def is_open(self) -> bool:
        """检查熔断器是否打开。"""

    def record_success(self):
        """记录成功，重置失败计数。"""

    def record_failure(self):
        """记录失败，超过阈值则打开熔断器。"""
```

## 3.5 调用流程

```
1. 计算缓存键 cache_key = _hash(system, user)
2. 查询缓存 if cache.get(cache_key): return cached
3. 检查熔断器 if circuit_breaker.is_open(): raise CircuitBreakerOpen
4. 指数退避重试:
   for attempt in range(max_retries):
       try:
           response = client.chat.completions.create(...)
           result = response.choices[0].message.content
           cache.set(cache_key, result)
           circuit_breaker.record_success()
           return result
       except Exception as e:
           circuit_breaker.record_failure()
           if attempt < max_retries - 1:
               sleep(2 ** attempt + random.uniform(0, 1))
           else:
               raise LLMCallFailed(str(e))
```

## 3.6 边界条件

| 场景 | 行为 |
|------|------|
| API返回空字符串 | 视为失败，触发重试 |
| API返回429 | 指数退避重试 |
| API返回500 | 指数退避重试 |
| 连续5次失败 | 熔断器打开30秒 |
| 缓存命中 | 直接返回，不调用API |
| system+user超过1M token | 截断或报错 |

## 5.4 完整Prompt

**System Prompt**（嵌入代码，不依赖外部文件）：

```
You are a Z3 constraint generator. Your task is to generate a constraint set at difficulty level {level}.

Difficulty definitions:
- Level 1: Linear Integer Arithmetic (LIA), ≤10 variables. Use only Int, +, -, *, <, >, <=, >=, ==.
- Level 2: Bit Vectors (BV), ≤20 variables. Use BitVec, &, |, ^, <<, >>, ==.
- Level 3: Mixed theories (LIA + BV + Array), ≤30 variables. Combine Int, BitVec, and Array sorts.

Requirements:
1. The constraint set MUST have a definite SAT or UNSAT answer (not unknown).
2. The constraint set MUST be solvable by Z3 within 10 seconds.
3. Output ONLY valid Python code that creates a Solver object and adds constraints.
4. Do NOT include solver.check() in the output. The verifier will call it.
5. Do NOT use any import other than "from z3 import *".
6. Do NOT use dangerous modules: os, sys, subprocess, shutil.

Output format:
```python
from z3 import *
x = Int('x')
y = Int('y')
solver = Solver()
solver.add(x > 5)
solver.add(y == x + 3)
solver.add(y < 15)
```

Generate a constraint set at level {level}. Output ONLY the code, no explanation.
```

**User Prompt**：

```
Generate a constraint set at difficulty level {level}.
```

## 5.5 处理流程

```
1. 构建system prompt（替换{level}）
2. 调用llm.call(system, user)
3. 提取代码（去除markdown代码块标记）
4. 调用verify_z3(code)验证任务有效性
5. 如果status=="error"或"unknown":
   - retry_count < max_retries: 重新生成
   - 否则: 抛出TaskGenerationFailed
6. 如果status=="sat"或"unsat":
   - 返回任务字典，expected=status
```

## 5.6 边界条件

| 场景 | 行为 |
|------|------|
| LLM输出包含markdown代码块 | 自动提取` ```python ... ``` `中的内容 |
| LLM输出为空 | 重试 |
| Z3验证超时 | 重试 |
| Z3返回unknown | 重试 |
| 重试3次仍失败 | 抛出TaskGenerationFailed，记录日志 |
| level参数不在[1,2,3] | 抛出ValueError |

## 9.4 相关性计算

```python
def _compute_relevance(exp: dict, keywords: list) -> float:
    exp_keywords = exp.get("context_keywords", [])
    if not exp_keywords or not keywords:
        return 0.0
    match_count = sum(1 for k in keywords if k in exp_keywords)
    base_score = match_count / len(keywords)
    confidence_weight = exp.get("confidence", 0.5)
    return base_score * 0.7 + confidence_weight * 0.3
```

## 13.3 完整Prompt

**System Prompt**：
```
You are a harness optimization agent. Given the current harness configuration and performance metrics, generate an improved version.

The harness consists of:
- system_prompt: The core instruction for task agents
- skill_library: A collection of problem-solving strategies
- task_difficulty_curve: Parameters controlling task difficulty progression

Requirements:

Generate an improved harness. Output ONLY the JSON.

## 13.4 处理流程

```
1. 检查停滞轮次（stagnation_rounds >= 20才触发）
2. 创建检查点（变异前）
3. 构建prompt，调用LLM
4. 解析JSON输出
5. 对new_harness的每个字段调用check_constitution
6. 如果任一字段违反宪法:

   - 返回success=True, new_harness, mutation_id

```

## 15.3 成本计算

```python
# DeepSeek V4 Flash 定价（元/百万token）
PRICING = {
    "cache_hit": 0.02,
    "cache_miss": 1.0,
    "output": 2.0
}

def _compute_cost(input_tokens: int, output_tokens: int, cache_hit: bool) -> float:
    input_price = PRICING["cache_hit"] if cache_hit else PRICING["cache_miss"]
    input_cost = input_tokens / 1_000_000 * input_price
    output_cost = output_tokens / 1_000_000 * PRICING["output"]
    return input_cost + output_cost
```
