五、单轮数据流（run_round.py 执行流程）

1
教师 Agent 生成 Z3 约束集任务
→ tasks/task_N.json
2
Z3 验证任务有效性（非矛盾、可判定）
→ eval/anchors/hard/task_N_valid.json
3
检索相关经验并注入 Prompt
← memory/experiences/*.json
4
学生 Agent 生成 Z3 求解代码
→ solutions/task_N_sol.py
5
Z3 执行求解代码，返回 SAT/UNSAT
→ eval/anchors/hard/task_N_result.json
6
对比期望结果，计算 Δ_t（自评-真实差距）
→ logs/{cond}/round_NNN.jsonl
7
经验蒸馏：成功→正规则，失败→负规则
→ memory/experiences/exp_N.json
8
难度自适应：成功率 >80% 升级，<30% 降级
→ state/current_level.txt
9
每20轮：创建检查点 + 停滞检测
→ checkpoints/round_NNN/
10
成本监控：累计 token 消耗，超预算告警
→ state/cost.json

七、ARGUS 的三条突破路径

路径一：假设空间递归扩展

Agent 不仅生成假设，还生成"生成假设的方法"，并递归改进这些方法。核心指标：假设空间扩展率。

代表方案：HyperAgents · Potentiality Dictionary

路径二：跨域结构迁移

识别不同知识领域间的共享数学结构，将一个领域的方法迁移到另一个领域。核心指标：跨域迁移率。

代表方案：BootLoops · GRAFT-ATHENA

路径三：元层面进化

不仅改进任务解决能力，还改进"改进任务解决能力的方法"。核心指标：元进化速度（性能提升的加速度）。

代表方案：DGM · HyperAgents · Nezha
