【任务】在现有ARGUS系统上实现裁判可靠度噪声注入，支持τ梯度实验。

【背景】
需系统测量"裁判可靠度τ"与"进化效率"的关系曲线，找到临界阈值τ_c。Ratchet给出了理论下界(1-τ)/2，但未在难度自适应场景中验证。

【交付物】修改以下文件：
1. scripts/verifier.py（增加噪声注入）
2. config.yaml（增加judge.reliability参数）
3. scripts/run_round.py（传递τ参数）
4. 新增：scripts/run_tau_sweep.py（τ梯度实验编排）

【实现要求】

**噪声注入**
- 修改verifier.py的verify_solution函数：
  def verify_solution(solution_code, expected, judge_reliability=1.0, noise_seed=None):
      """
      judge_reliability: τ ∈ [0, 1]
      τ=1.0: 完美裁判（Z3真实结果）
      τ<1.0: 以概率(1-τ)/2翻转结果
      """
      true_result = _z3_verify(solution_code)
      if judge_reliability < 1.0:
          rng = random.Random(noise_seed)
          if rng.random() < (1 - judge_reliability) / 2:
              # SAT↔UNSAT翻转
              if true_result["status"] == "sat":
                  true_result["status"] = "unsat"
                  true_result["model"] = None
              elif true_result["status"] == "unsat":
                  true_result["status"] = "sat"
          # error/unknown不翻转
      return true_result

**τ梯度实验编排**
- 新增run_tau_sweep.py，参数：
  --tau_values 0.55,0.60,0.65,0.70,0.75,0.80,0.90,1.00
  --conditions B,D
  --rounds 50
  --level 1
- 对每个τ值，跑条件B和D各50轮（仅L1任务，隔离生成器瓶颈）
- 输出：reports/tau_sweep/{tau}/condition_{B,D}/round_*.jsonl

**τ_c检测**
- 新增scripts/detect_tau_c.py
- 读取所有τ值的Δ_t曲线
- 检测"稳定→持续上升"的拐点：
  - 计算每个τ值下后25轮的Δ_t均值
  - 如果后25轮均值 > 前25轮均值的1.5倍，标记为"退化"
  - τ_c = 最大的"稳定"τ值
- 输出：reports/tau_c_analysis.md，含：
  - τ vs 最终Δ_t的表格
  - τ vs 最终Δ_t的曲线图（τ_c位置标注）
  - τ_c的经验值

【验收标准】
- τ=1.0时，条件B的Δ_t=0.00（与已有数据一致）
- τ=0.5时，Δ_t应显著上升（验证噪声注入有效）
- detect_tau_c.py能正确识别拐点
- 总成本<20元（8个τ值×2条件×50轮=800轮）

【输出报告格式】
reports/tau_c_analysis.md 必须包含：
1. 实验设置表
2. τ vs Δ_t的原始数据表
3. τ_c的确定过程和理由
4. 与Ratchet理论值(1-τ)/2的对比
5. 可直接用于论文的图表（PNG，300 DPI）
